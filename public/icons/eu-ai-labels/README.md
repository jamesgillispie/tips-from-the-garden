# EU AI content labels

Official European Commission AI-label assets downloaded from:

- SVG package: https://ec.europa.eu/newsroom/dae/redirection/document/129546
- PNG package: https://ec.europa.eu/newsroom/dae/redirection/document/129547

Files were renamed for stable application paths; artwork is otherwise unchanged.
The application uses `ai-label-black.svg` on web pages and
`ai-label-black.png` in PDFs. Re-check the Commission's current usage guidance
before redistributing these assets outside this project.
